# OpenFVR

Documentation of 4X Technologies's Phoenix VR engine used in adventure games like Amerzone, The messenger and some Dracula adventure games.

## Current status

This project is now archived, as Phoenix VR games are (or will be) at least parially supported in [ScummVM](https://github.com/scummvm/scummvm).  
Feel free to use the [OpenPhoenix](https://github.com/Alys-Elica/OpenPhoenix) library as you like.
